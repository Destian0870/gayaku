# Gayaku — Ubiquitous Language

Glossary of domain terms. No implementation details.

## Terms

- **Look**: a styled outfit suggestion (title, subtitle, style tag, image). Rendered as "Today's Look". Distinct from a garment.
- **WardrobeItem**: a single owned garment (name, category, image). Rendered in "Recently Added". A Look may reference multiple WardrobeItems but is not itself one.
- **Style tag**: short occasion label on a Look (e.g. "Casual Chic").
- **QuickAction**: a shortcut card to a destination not yet built (e.g. Your Favorite, Plan Week).
- **Greeting**: time-of-day salutation plus the user's name (e.g. "Good Evening, Isabella").
